# Panduan SINTESA untuk admin dan pihak BPN

Panduan ini menjelaskan pemakaian **SINTESA 1.2.5**, disesuaikan dari dokumentasi
project aplikasi. Disiapkan 30 Oktober 2026.

## Mulai di sini

| Kebutuhan | Panduan |
| --- | --- |
| Mengenal alur pemakaian sehari-hari | [Panduan pengguna](PANDUAN_PENGGUNA.md) |
| Memasang atau memperbarui aplikasi | [Instalasi Windows](../INSTALASI.md) |
| Memilih cara menambah dan memperbarui data | [Kelola data](KELOLA_DATA.md) |
| Memperbaiki nama PDF yang ditolak | [Format nama PDF](NAMA_PDF.md) |
| Mengisi metadata melalui rekap online | [Google Sheets](REKAP_ONLINE.md) |
| Melengkapi metadata PDF atau mengulang ekstraksi | [OCR dan proses ulang](OCR_DAN_PROSES_ULANG.md) |
| Memindahkan metadata dan menyimpan laporan | [Pertukaran data dan laporan](PERTUKARAN_DATA.md) |
| Melayani pencarian dan permintaan PDF di jaringan kantor | [Service web dan client](SERVICE_LAN.md) |
| Memahami keamanan login Google | [Keamanan sesi Google](KEAMANAN_TOKEN.md) |

Alur awal yang disarankan: **catat metadata utama → isi dari rekap → periksa hasil
pencarian → lakukan OCR jika diperlukan → layani client sesuai kebutuhan kantor**.
OCR bukan syarat agar metadata utama dapat dicari.

Paket metadata bukan cadangan lengkap aplikasi. Hasil OCR masih perlu diperiksa,
dan link Drive tersimpan tidak otomatis memberi izin Google kepada pemohon.
