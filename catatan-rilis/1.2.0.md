# SINTESA 1.2.0

- Rekap dari link Google Sheets dengan pilihan lembar, pemetaan, pratinjau dan sumber tersimpan.
- Logo admin/client serta ikon executable dan installer.
- Token Google terenkripsi Windows per pengguna, migrasi token lama dan logout lokal.
- PDF Drive untuk OCR dibatasi 1 GB per berkas; preview tetap 200 MB.
- Keterbacaan dan penataan UI, pencarian client serta riwayat permintaan diperbarui.
- Referensi Google Drive ditempatkan lebih atas pada Detail dokumen.

Google Sheets harus berupa spreadsheet asli, bukan file Excel yang hanya disimpan
di Drive. Akun Google harus memiliki izin baca; API Sheets perlu aktif.

Installer tidak membawa credentials, token, database, PDF atau data kantor.
Data pengguna berada terpisah dari folder program. Token lama dimigrasikan saat
menghubungkan Google berikutnya. Ketika pindah komputer/akun Windows, login ulang.

Prasyarat: Windows 10/11 x64 dan WebView2 Runtime. Tesseract ind/eng/osd dibundel.
Uji executable lulus untuk UI/logo, OCR, service lokal, dan enkripsi token Windows.
Pemasangan/upgrade belum diuji otomatis karena instalasi existing dipertahankan.
Uji akun Google live dan komputer kantor tetap diperlukan.
