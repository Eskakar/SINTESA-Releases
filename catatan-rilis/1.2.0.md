# SINTESA v1.2.0 — Integrasi Google Sheets, Pembaruan Tampilan & Keamanan Token

SINTESA membantu petugas mengelola dan menemukan berkas pertanahan berdasarkan
metadata yang tercatat. Versi 1.2.0 menambahkan sumber rekap online, memperjelas
tampilan admin/client, serta memperkuat penyimpanan sesi Google di Windows.

## Yang baru dan diperbaiki

### Rekap Google Sheets

- Ambil metadata langsung dari link Google Sheets, selain file Excel/CSV.
- Pilih lembar, cocokkan kolom, lalu periksa pratinjau sebelum menerapkan data.
- Gunakan kembali sumber online yang pernah diterapkan beserta pemetaan kolomnya.
- Metadata dapat membentuk arsip baru meskipun PDF belum ditautkan. Pemuatan rekap tidak menjalankan OCR.

Gunakan **Google Spreadsheet asli**. File `.xlsx` yang hanya disimpan di Drive
perlu diunduh untuk impor file, atau disimpan sebagai Google Spreadsheet terlebih
dahulu. Akun Google harus memiliki izin membaca rekap dan Google Sheets API perlu
aktif pada konfigurasi yang disiapkan pengelola. Pembaruan rekap dilakukan manual.

### Tampilan dan pencarian

- Logo SINTESA pada admin/client serta ikon aplikasi dan installer.
- Ukuran huruf diperbesar dan Kelola data dikelompokkan berdasarkan kegiatan.
- Referensi Google Drive berada lebih atas pada Detail dokumen agar mudah diakses.
- Hasil pencarian client mengutamakan kecocokan No. DI/nama PDF dan tahun, lalu nomor berkas serta metadata lainnya.
- Satu kolom pencarian client mendukung nama lengkap dan NIK utuh yang sudah tercatat; NIK tidak ditampilkan dalam hasil.
- Permintaan terbaru tampil pada halaman pencarian, sementara riwayatnya tersedia melalui menu Permintaan saya.

### Sesi Google dan pemrosesan PDF

- Token login Google disimpan terenkripsi dan terikat pada akun Windows yang digunakan.
- Token lama dipindahkan saat menghubungkan Google berikutnya, lalu dihapus setelah penyimpanan terenkripsi berhasil.
- Unduhan PDF Drive untuk ekstraksi/OCR dibatasi **1 GB per berkas** dan diproses satu per satu. Preview Drive tetap dibatasi **200 MB**.
- Salinan PDF unduhan sementara dibersihkan setelah pemrosesan; PDF asli di Google Drive tetap ada.

Enkripsi token tidak membatasi orang yang menggunakan akun Windows yang sama
atau memakai SINTESA yang sudah terhubung. Saat berpindah komputer/akun Windows,
hubungkan Google kembali.

## Unduh dan pasang

Pada bagian **Assets** rilis ini, unduh:

- **`SINTESA-Setup-1.2.0-x64.exe`** — installer Windows.
- `SHA256SUMS-1.2.0.txt` — checksum untuk memeriksa file unduhan.
- `BUILD-INFO-1.2.0.json` — informasi hasil build dan pemeriksaan.

File **Source code (zip/tar.gz)** yang dibuat otomatis oleh GitHub adalah arsip
repository dokumentasi ini, bukan installer SINTESA.

Kebutuhan: **Windows 10/11 64 bit** dan **Microsoft Edge WebView2 Runtime**.
Python dan Tesseract beserta model OCR Indonesia/Inggris sudah dibundel.
Installer tidak membawa credentials Google, token, database, atau PDF/data kantor.
Fitur lokal dapat digunakan tanpa konfigurasi Google.

Untuk memperbarui aplikasi, tutup SINTESA dan cadangkan database saat aplikasi
tertutup sebelum menjalankan installer baru. Data pengguna disimpan terpisah
dari folder program.

## Pemeriksaan versi ini

- 160 pengujian aplikasi lulus sebelum build.
- Uji executable lulus, termasuk tampilan/logo, OCR, service lokal, dan enkripsi token Windows.
- Pemasangan/upgrade installer belum diuji otomatis pada instalasi baru; instalasi yang sudah ada di komputer pengujian dipertahankan.
- Uji kantor serta akses akun Google langsung tetap perlu dilakukan sesuai lingkungan pemakaian.

Service client ditujukan untuk jaringan kantor tepercaya dan masih memakai HTTP
tanpa login SINTESA. Pencarian dapat dipakai tanpa OCR jika metadata sudah dicatat.
Hasil OCR tetap perlu diverifikasi; paket `.sintesa` adalah pertukaran metadata,
bukan cadangan lengkap aplikasi.

Jika menemukan masalah, laporkan versi dan langkah kejadiannya melalui
[Issues](https://github.com/Eskakar/SINTESA-Releases/issues), tanpa melampirkan
data pribadi, PDF warkah, credentials, atau token.
