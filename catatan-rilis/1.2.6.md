# SINTESA v1.2.6 — Statistik Service Web & Perlindungan Hasil OCR

## Pembaruan dari v1.2.5

- **Statistik Service web.** Admin dapat memilih tahun untuk melihat jumlah pencarian dan permintaan akses PDF per bulan, termasuk keputusan disetujui, ditolak, atau menunggu. Pencarian dengan kata kunci atau filter mulai dihitung setelah pembaruan; pencarian lama tidak ditambahkan secara surut.
- **Proses ulang OCR lebih aman.** Hasil baru menggantikan hasil lama hanya setelah proses berhasil. Jika ekstraksi gagal, tidak menghasilkan teks, atau dibatalkan, hasil lama dipertahankan. Pada proses ulang satu PDF, perubahan sumber ikut diterapkan hanya setelah proses berhasil.
- **Privasi hasil pencarian client.** Nama kandidat tetap dapat dicari, tetapi daftar nama kandidat tidak lagi dikirim dalam respons hasil pencarian client.
- **Tampilan.** Panel Service web menata statistik, permintaan akses, dan log dalam tab terpisah. Tata letak beberapa bagian admin juga dirapikan.

## Unduh dan pasang

Pada bagian **Assets**, unduh `SINTESA-Setup-1.2.6-x64.exe`. Gunakan `SHA256SUMS-1.2.6.txt` untuk memeriksa file unduhan. Rincian build tersedia di `BUILD-INFO-1.2.6.json`.

Installer memerlukan Windows 10/11 x64 dan WebView2. Python dan Tesseract sudah dibundel. Jika WebView2 belum terpasang, pemasangannya membutuhkan internet. Installer tidak menyertakan credentials, token, database, atau PDF pengguna.

Tutup SINTESA dan cadangkan database sebelum memperbarui. Data pengguna disimpan terpisah dari folder program. Lihat [panduan instalasi](https://github.com/Eskakar/SINTESA-Releases/blob/HEAD/INSTALASI.md).
