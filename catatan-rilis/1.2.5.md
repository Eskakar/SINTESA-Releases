# SINTESA v1.2.5 — Folder Drive Bertingkat & Penyempurnaan Tampilan

Paket dibangun dari source terbaru pada 30 Oktober 2026. Dibuat oleh Nabil & Verrel.

## Pembaruan dari 1.2.1

### Folder Google Drive bertingkat

- Memilih folder utama turut memuat PDF dalam subfolder yang dapat diakses akun.
- Daftar PDF menampilkan jalur subfolder, progres pemuatan, dan pembatalan.
- Perbarui folder dan pratinjau proses ulang OCR memakai penelusuran yang sama.
- PDF dikenali lewat ID Drive; sinkronisasi biasa tidak mengulang OCR yang selesai.
- Shortcut tidak diikuti. Batas per sumber: 50.000 PDF, 10.000 folder termasuk
  folder utama, dan 100 tingkat subfolder. Pelampauan atau penelusuran tidak
  lengkap dilaporkan sebagai kegagalan, bukan dipotong diam-diam.
- Aturan nama PDF tetap berlaku. Tahun atau nomor DI tidak ditebak dari nama folder.

### Tampilan dan laporan admin

- Bantuan folder, rekap, dan pertukaran menjadi ikon **?** di pojok panel.
  Keterangan dapat ditutup dengan klik luar atau Escape.
- Toolbar Drive memisahkan pagination, pemilihan, dan proses PDF. Pager Kelola
  data dipusatkan serta tombol menyesuaikan ruang pada layar sempit.
- Zoom admin **50–150%** dengan kontrol header dan shortcut yang sudah tersedia.
  Default 100% saat membuka aplikasi; zoom tidak mengubah DPI OCR.
- Laporan nama ditolak dapat menyimpan **satu entri terpilih** ke CSV berisi
  nama, sumber, dan alasan. Ini ekspor laporan, bukan unduhan PDF.
  Ekspor seluruh laporan tetap tersedia.
- Kredit **Dibuat oleh Nabil & Verrel** tampil di footer admin dan web client.

## Unduh dan pasang

Lampiran paket:

- **SINTESA-Setup-1.2.5-x64.exe** — installer Windows x64.
- **SHA256SUMS-1.2.5.txt** — checksum file installer.
- **BUILD-INFO-1.2.5.json** — informasi build dan hasil pemeriksaan.

File Source code (zip/tar.gz) dari GitHub adalah arsip repository dokumentasi,
bukan installer. Gunakan Windows 10/11 x64 dengan Microsoft Edge WebView2.
Python dan Tesseract ind/eng/osd sudah dibundel. Pemasangan WebView2 memerlukan
internet jika runtime belum tersedia.

Installer tidak membawa credentials Google, token, database, atau PDF pengguna.
Import/OCR lokal tetap bisa digunakan tanpa login Google. Tutup SINTESA dan
cadangkan database sebelum upgrade. Data pengguna terpisah dari folder program.

## Pemeriksaan dan batas

Hasil pemeriksaan build tercatat pada manifest yang disertakan. Pengujian memakai
data sintetis; akses akun Drive/Sheets kantor, ketepatan OCR, dan performa pada
RAM 4 GB/i5 generasi 3 tetap perlu diuji pada lingkungan pengguna. Instalasi
existing di komputer build dipertahankan; install/upgrade tidak dijalankan di sana.

Penyempurnaan filter/kolom rekap permintaan CSV masih rancangan dan **belum
ditambahkan** pada versi ini. Ekspor permintaan yang sudah tersedia tetap berlaku.

Laporkan masalah melalui Issues dengan versi, pesan, dan langkah kejadian.
Jangan melampirkan PDF warkah, identitas, credentials, token, atau database pribadi.
