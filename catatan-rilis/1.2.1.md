# SINTESA v1.2.1 — Perbaikan Drive, Rekap, dan Tampilan Admin

Paket lokal diperbarui pada 29 Oktober 2026. Rilis GitHub 1.2.0 tetap tersedia;
paket 1.2.1 ini belum dipublikasikan otomatis.

## Perubahan dari 1.2.0

- Progres unduhan PDF Drive menampilkan ukuran yang diterima. Koneksi yang
  terputus atau unduhan yang dibatasi diberi pesan yang lebih jelas.
- Dukungan unduhan Shared Drive, timeout per permintaan, dan pembersihan file
  parsial saat gagal atau dibatalkan.
- Excel/Google Sheets menerima sel kosong di ujung baris. Data tanpa judul kolom
  tetap ditolak. Pemuatan rekap online menampilkan tahap dan baris yang dibaca.
- Teks sekunder admin dibuat lebih gelap. Zoom admin 75–150% melalui tombol
  header, Ctrl +/−/0, atau Ctrl + roda mouse; kembali 100% saat membuka aplikasi.
- Pemberitahuan nama PDF dapat ditutup selama sesi. Pemeriksaan baru yang
  menolak nama tetap memberi pemberitahuan; laporan lama tidak muncul lagi saat
  restart dan tetap tersedia melalui Kelola data → Laporan.

## Pemasangan

Unduh `SINTESA-Setup-1.2.1-x64.exe` beserta `SHA256SUMS-1.2.1.txt` dari paket
yang sama. Informasi build dan pengujian ada di `BUILD-INFO-1.2.1.json`.
Installer memerlukan Windows 10/11 x64 dan WebView2. Python dan Tesseract
ind/eng/osd sudah disertakan. Bootstrapper WebView2 membutuhkan internet bila
runtime belum terpasang.

Tutup SINTESA dan cadangkan database sebelum memperbarui aplikasi. Data pengguna
terpisah dari folder program. Credentials, token, database, dan PDF/data kantor
tidak disertakan dalam installer.

## Batas

Pengujian sintetis tidak membuktikan akses unduhan akun Google pengguna atau
ketepatan seluruh hasil OCR. Akses Drive/Sheets live, komputer kantor, dan
pemasangan pada instalasi existing tetap perlu diperiksa oleh pengguna.
Daftar pemeriksaan build terbaru tercatat pada manifest paket.
